## Root cause and validation

The application previously embedded Turkish presentation strings directly in the UI and had no display-language state. A presentation-only localization layer now keeps translation logic values stable while translating visible copy. During real GUI validation, a one-way window-title issue was found and fixed before delivery.

Validation performed:

- `python -m py_compile subtitle_translator_gui.py ui_localization.py`
- `python belge_uret.py --kontrol` — guide current
- Real `App()` smoke: English startup, switch to Turkish, switch back to English — passed
- `python -m unittest discover -s tests` — 5,482 passed, 6 skipped

No paid API calls were made. The skipped tests are environment-dependent skips reported by the existing suite. Translation reports and some diagnostic output remain Turkish as documented in the README.
