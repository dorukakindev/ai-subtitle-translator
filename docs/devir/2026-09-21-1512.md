## Audited upstream changes

Five merged Devin PRs were fetched and reviewed before the local clone was
fast-forwarded. They add two runtime fixes, documentation/link CI, refreshed
public documentation, a corrected Turkish README anchor, and a changelog.

The live-provider sentinel fix is valid: `time.monotonic()` measures time since
boot, so using `0.0` as "never passed" could suppress the first real probe when
uptime was below the 120-second TTL. The new `None` sentinel removes that false
pass and has a deterministic regression test.

The hybrid Batch Auto-Glossary gate is also valid: output that failed the
quality/delivery gate must not trigger a paid helper request or offer terms from
unverified translation. The upstream change correctly skips that request.

## Additional defect found and repaired

The upstream change stored `reason: quality_failed`, but the quality report
ignored the reason and displayed the unrelated "no source/translation pairs"
message. The other successful skip paths also exited before recording an
Auto-Glossary status, so their reports said only that no run record existed.

The repair now:

- renders Auto-Glossary skip reasons through the shared pass-reason table;
- records `unresolved_markers`, `delivery_failed`, or `quality_failed` in the
  shared plain sync/Batch writer and the synchronous hybrid flow;
- keeps the upstream hybrid Batch quality gate intact;
- closes the source file cleanly in the new parity test and extends coverage to
  all three failure reasons.
